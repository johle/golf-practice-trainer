# Golf Practice Trainer
Private downloads for friends playing This Is Golf on Windows and Steam. Requires your own supported Steam installation (currently build 25921204). This package contains trainer code only, with no game assets.
## Install
1. Open [Releases](https://github.com/johle/golf-practice-trainer/releases/latest) and download Golf-Practice-1.0.0.zip.
2. Extract the ZIP and double-click Setup.cmd.
3. Confirm the Steam game folder and choose a separate trainer folder.
4. Click Play, or use Start Practice.cmd in the trainer folder.
F6 opens the practice tools. F6 -> Trainer updates opens the update manager.
## Updates
Close the practice game, download the next release ZIP, and choose Install shared ZIP in Trainer Manager. Settings, calibration and shot history are preserved. Restore previous version is available if needed. The trainer leaves your Steam installation unchanged.
Private GitHub downloads require signing in with an account that has access to this repository. A link alone does not grant access. Automatic private GitHub downloads are not configured in this release; use Install shared ZIP.
